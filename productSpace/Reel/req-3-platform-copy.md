# Req 3: Platform-Tailored Captions & Copy

## Summary
Copy engine tailoring clip messages for 5 distinct platforms based on `platforms.yaml`:
- **LinkedIn:** hook before 210 char cut, short punchy paragraphs, insight-led, 0-3 hashtags, conversational question CTA.
- **Instagram Reels:** 1st line caption hook, line breaks, 3-8 hashtags, on-screen text overlays, comment/save CTA.
- **YouTube Shorts:** punchy title <=100 chars, SEO description with keywords, pinned comment.
- **X (Twitter):** <=280 char single post + optional 3-5 post thread.
- **TikTok:** ultra-short hook, trending hashtag style, text beats.

## Key Features
- Platform feed mockup preview tabs (realistic layout).
- A/B hook variants.
- Real-time "Voice Match Score" compared against [[req-4-brand-voice-memory]].
